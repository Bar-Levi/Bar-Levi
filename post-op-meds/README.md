# מעקב תרופות אחרי ניתוח פה · Post-Op Meds PWA

אפליקציית PWA בעברית (RTL) לתזמון תרופות, נעילות בטיחות ותזכורות לאחר ניתוח בחלל הפה.
עובדת 100% אופליין, ניתנת להתקנה על מסך הבית, וכל הנתונים נשמרים במכשיר בלבד.

> ⚠️ **כלי עזר למעקב בלבד – אינו מחליף ייעוץ רפואי.** יש לפעול לפי הוראות הרופא/המנתח והעלון לצרכן.
> אם ההוראות שקיבלת שונות מהכללים כאן – ההוראות של הרופא גוברות.

## התקנה והרצה

```bash
cd post-op-meds
npm install
npm run dev        # http://localhost:5173 (Service Worker פעיל גם בפיתוח)
```

| פקודה | תיאור |
|---|---|
| `npm run dev` | שרת פיתוח |
| `npm run build` | בדיקת טיפוסים + בנייה ל-`dist/` (כולל Service Worker ו-manifest) |
| `npm run preview` | הגשת הבנייה מקומית (לבדיקת התקנה ואופליין) |
| `npm test` | בדיקות יחידה למנוע הכללים הקליניים (Vitest) |

**פריסה:** את תיקיית `dist/` אפשר להעלות לכל אחסון סטטי עם HTTPS (Netlify, Vercel, GitHub Pages, Cloudflare Pages).
PWA, Service Worker והתראות דורשים HTTPS (או `localhost`).

## כללים קליניים מיושמים

| תרופה | תדירות | נעילה (אדום) | הערות |
|---|---|---|---|
| **ארקוקסיה 90 מ״ג** (Etoricoxib) | פעם ב-24 שעות, בבוקר עם אוכל | עד 24 שעות מהמנה האחרונה | חסימה מוחלטת של נורופן/איבופרופן ו-NSAIDs נוספים; אישור „נלקח עם אוכל” |
| **רוקסט פלוס** (Paracetamol/Codeine/Caffeine) | לפי הצורך, עד 4 ביום | מרווח מינימלי 4–6 ש׳ (ניתן לכיוון) **או** 4 טבליות ב-24 שעות מתגלגלות | אזהרת נהיגה/טשטוש; המלצה למרווח 6 ש׳ |
| **מוקסיפן** (Amoxicillin) | 3 ביום, כל ~6 שעות בשעות ערות | פחות מ-4 ש׳ מהמנה הקודמת, או מנה 4 באותו יום | מעקב היענות ומנות שהוחמצו – ללא המלצה להכפיל מנה |

**מקרא סטטוס:** 🟢 מותר לקחת לפי הצורך · 🟡 זמן מנה מומלץ · 🔴 נעול – להמתין למרווח בטיחות

- „יום טיפול” מתחיל ב-04:00 (מנה ב-01:00 בלילה נספרת ליום הקודם).
- מנות מתוזמנות שנופלות בשעות השינה (ברירת מחדל 23:00–07:00) נדחות לשעת הקימה.
- הבדיקות מתבצעות גם ברישום בדיעבד ובעריכה (חלון 24 שעות מתגלגל אמיתי).

## תכונות

- **לוח בקרה** – כרטיס לכל תרופה: מנה אחרונה, ספירה לאחור חיה, סטטוס צבעוני וכפתור „רשום נטילה עכשיו” עם אישור.
- **רישום** – עכשיו או בשעה אחרת, „נלקח עם אוכל / מים להגנה על הקיבה”, הערה (למשל רמת כאב).
- **היסטוריה** – ציר זמן הפוך עם סינון, ביטול תוך 60 שניות, עריכה ומחיקה.
- **ייצוא** – שיתוף/העתקה כטקסט לרופא (WhatsApp/מייל), קובץ טקסט, JSON; ייבוא גיבוי.
- **תזכורות** – התראת מערכת + צליל + רטט כשהטיימר מגיע ל-0, ובאנר בתוך האפליקציה כגיבוי תמידי.
- **סימני אזהרה** – רשימה מתקפלת עם חיוג ישיר למד״א 101.

## התראות – מה עובד איפה

אפליקציית רשת ללא שרת Push **אינה יכולה להבטיח** התראה כשהיא סגורה לגמרי. המימוש:

1. **אפליקציה פתוחה / ברקע** (כל הדפדפנים): מתזמן פנימי בודק כל שנייה ומפעיל התראת מערכת דרך ה-Service Worker, צליל (Web Audio) ורטט.
2. **Notification Triggers** (דפדפני Chromium שתומכים): התראות עתידיות מתוזמנות מראש ב-Service Worker ומופיעות גם כשהאפליקציה סגורה.
3. **iOS**: התראות זמינות רק לאחר „הוספה למסך הבית” (iOS 16.4+) וכשהאפליקציה פעילה. האפליקציה מזהה זאת ומציגה הנחיות.
4. **גיבוי תמידי**: באנרים צהובים/כתומים בראש לוח הבקרה, נקודה בתפריט וכותרת הלשונית `(1) ⏰`.

לאנטיביוטיקה מומלץ להגדיר גם שעון מעורר בטלפון.

## מבנה הקוד

```
src/
├── lib/                  # לוגיקה טהורה, ללא React
│   ├── medications.ts    # הגדרות התרופות והפרמטרים הקליניים
│   ├── rules.ts          # מנוע הסטטוס/נעילות/ולידציה/היענות  ← rules.test.ts
│   ├── time.ts           # שעות ערות, יום טיפול, פורמט עברי
│   ├── storage.ts        # localStorage עם סניטציה וגרסה
│   ├── alerts.ts         # התראות, צליל, רטט, Notification Triggers
│   └── export.ts         # ייצוא טקסט/JSON ושיתוף
├── hooks/                # store (Context + reducer), useNow, useReminders
├── components/           # כרטיסים, דיאלוגים, היסטוריה, הגדרות, באנרים
├── sw.ts                 # Service Worker (Workbox precache + התראות)
└── App.tsx
```

**Stack:** Vite · React 19 · TypeScript · Tailwind CSS v4 · lucide-react · vite-plugin-pwa (injectManifest).

**פרטיות:** אין שרת ואין איסוף נתונים. הכל ב-`localStorage` של המכשיר (עם בקשת `navigator.storage.persist()`); הגופן Heebo נטען מ-Google Fonts ונשמר במטמון לשימוש אופליין.
